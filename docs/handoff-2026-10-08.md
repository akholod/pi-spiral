## Decisions already made (in the plan)

- Runner = plain npm library (working name `pi-agent-runner`), not a Pi
  extension; Pi packages as peerDependencies.
- In-process children via `createAgentSession` + `DefaultResourceLoader`
  (`noExtensions` or ambient-minus-self), serialized creation, shutdown =
  emit `session_shutdown` (5 s cap) → `dispose()` in `finally`.
- Structured output ONLY via a `submit_result` tool call, one correction
  retry; never parse JSON from prose.
- Spiral parity constraint: role prompt REPLACES the system prompt, no
  context files, no skills (matches current pi-subagents runtime-agent
  behavior).
- Opium phase 4 scope: message/cancel-retain/revive are IN (slim contract),
  forked context is OUT.
- Timeouts must pause while a permission dialog is open for the child
  (see incident below).
